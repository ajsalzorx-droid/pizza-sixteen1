# Pizza Sixteen

Marketing and menu site for Pizza Sixteen, built with [Next.js](https://nextjs.org) (App Router), React, Tailwind CSS and Framer Motion.

## Prerequisites

- Node.js `>=20.9.0`

## Quick Start

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Project Shape

- `app/page.tsx` – home page (hero, menu, cart)
- `app/menu-data.ts` – menu items, categories and prices
- `app/layout.tsx` – fonts, metadata and structured data
- `app/globals.css` – global styles (Tailwind)
- `public/images/` – logos and menu photos

## Commands

- `npm run dev` – start the dev server
- `npm run build` – production build
- `npm start` – serve the production build
- `npm run lint` – run ESLint
